# Credit Risk Intelligence

### End to End Loan Default Prediction and Risk Scoring System

## Overview

Credit Risk Intelligence is a machine learning project designed to investigate loan default risk and support data driven lending decisions.

The project follows an end to end data science workflow, including data ingestion, validation, statistical analysis, exploratory data analysis, feature engineering, predictive modeling, model evaluation, risk scoring, and deployment.

## Business Problem

Financial institutions face the challenge of identifying borrowers who may be unable to repay their loans.

Poor risk assessment can result in financial losses, while overly restrictive lending decisions may reduce access to credit for creditworthy borrowers.

## Objectives

- Analyze historical loan repayment behavior.
- Identify factors associated with default.
- Develop models to estimate loan default probability.
- Evaluate predictive performance using appropriate metrics.
- Develop a risk scoring framework.
- Explore lending decision strategies.
- Deploy a prediction API.
- Establish model monitoring practices.

## Project Structure

The project is organized into reusable source code, notebooks, data directories, tests, documentation, reports, and model artifacts.

## Technologies

Python, Pandas, NumPy, Scikit-learn, SciPy, Statsmodels, Matplotlib, Seaborn, Pytest, FastAPI, Git, and Docker.
